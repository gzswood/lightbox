这个软件能做什么

把桌面上零散的快捷方式收进一个个小方盒，桌面立刻清爽，用的时候点一下盒子就都出来了。
桌面上的图标收纳盒
小方盒贴在桌面层，或嵌入任务栏，小巧不占地方
拖进去就收纳
把桌面上的快捷方式拖到盒子上，文件会真正移动到盒子里，桌面图标随即消失。
点开即用
点盒子弹出面板，单击图标启动程序；右键可单独放回桌面或从盒子移除。
拖动排序
在面板里按住图标拖动就能调整顺序，松手即保存，下次打开还是这个顺序。
拖出去就放回桌面
把图标从面板里拖到桌面（或任意文件夹窗口）松手，就是移出去，不用先打开目录。
解散收纳盒
一键把盒子里所有图标放回桌面，盒子留着空着也不影响使用。
嵌入任务栏
拖动收纳盒到任务栏或点击收纳盒右键菜单嵌入任务栏，可鼠标拖回桌面或右键菜单移出任务栏
外观自己调
收纳盒和面板的底色分别可调，内置取色器和屏幕吸管；文字颜色按背景自动选深或浅，图标可自定义。
置顶 / 开机自启 / 托盘常驻
常用盒子可以置顶；开机自动启动；托盘图标右键可新建盒子、自动排序、打开设置、退出。
绿色单文件
只有一个 exe，无需安装。配置和收纳内容都放在 exe 同级目录，整个文件夹拷到别的电脑就能继续用。
支持高 DPI 和多屏
跟随 Windows 缩放（100% / 125% / 150%…），双屏混合缩放下盒子位置和取色都准。
自动检查更新
每天后台静默检查一次新版本，不弹窗、不打断操作；有更新时只在设置页左下角的版本号处显示红色提醒，也可以随时在托盘菜单里手动检查。

第一次使用

  1. 下载 lightbox.exe，放到一个专门的文件夹里（比如 D:\LightBox）双击运行。不需要安装。
  2. 首次运行会看到桌面底部出现两个空盒子：系统工具、办公工具。
  3. 把桌面上的快捷方式用鼠标拖到盒子上松手，快捷方式就被收进去了，桌面上的那个图标会消失。
  4. 点一下盒子，弹出面板，里面就是收纳好的图标。单击启动，按住拖动可以换顺序，拖到面板外面就是放回桌面。
  5. 想改名字或图标：右键点盒子 →「重命名」/「设置图标…」（图标只支持 .ico 文件）。
  6. 想多分几类：右键盒子 →「新建收纳盒」，或右键托盘图标 →「新建收纳盒」。
  7. 盒子乱了位置：右键托盘图标 →「自动排序」，所有盒子会回到桌面下边缘、整齐排一行。
  8. 外观、开机自启、数据目录：右键盒子 →「设置LightBox」，或右键托盘图标 →「设置…」。

操作结果

第一次运行被 Windows 拦了？
因为没有购买代码签名证书，Windows 可能显示「已保护你的电脑」。点「更多信息」→「仍要运行」即可，程序不联网上传任何数据， 唯一的对外请求是每天读取一次更新清单。

数据放在哪

默认都在 exe 同级的目录里：config.json（盒子列表、顺序、外观设置）和 boxes\（每个盒子一个子目录，里面就是快捷方式本身）。 如果 exe 放在 C:\Program Files 这类没有写权限的位置，会自动改用 %LOCALAPPDATA%\LightBox，实际路径可以在「设置」里点「打开数据目录」查看。

备份：把 config.json 和 boxes 目录连同 exe 一起拷走即可， 盒子、顺序、外观设置和收纳的快捷方式都会跟着过去。
