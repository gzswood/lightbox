# LightBox 更新记录

## v1.0.1
<small>2026-11-14</small>

**交互收尾：菜单重新归拢、补齐图标，顺手修掉两个不顺手的地方。** 没有配置变更，
升级后盒子、图标、外观设置全部原样保留，**不触发任何迁移**。

- 变更 原来的「桌面模式」和「嵌入任务栏」两项合并成 **「主界面模式」二级菜单**，
  展开后二选一，当前模式前面打勾；
- 优化 **主面板菜单**排列项目优化；
- 新增 **菜单项图标**：主界面模式（显示器）、设置（齿轮）、新建盒子（加号）、
  解散盒子（向右箭头）、删除盒子（垃圾桶）；
- 优化 托盘右键菜单优化，并给「设置…」补了齿轮图标；
- 新增 **面板空白处右键**：弹出的菜单与标题栏「更多」**完全一致**；
- 修复 图标右键「属性」原来默认停在**「常规」**页，现在直接激活**「快捷方式」**页。

## v1.0.0
<small>2026-11-13</small>

**大版本：全量重写 + 产品形态变更。** 从 Tauri + React 换成 **纯 Rust + Win32**，
不再捆绑 WebView2。收纳盒从「多个盒子各自摆放」改为「一条任务栏长条」，
**部分 0.9.x 特性不再保留**，详见下方升级说明。

- 重写 整个程序改成**单进程、单消息循环**的原生 Win32 实现，**不再捆绑 WebView2**，
  不再有 Node 进程 —— 这是 Win11 上「卡顿」「点击收纳盒无响应」的根因；
- 优化 exe 从 **3.9 MB 降到约 1.0 MB**（`opt-level=s` + LTO + strip，以实际产物为准）；
- 优化 进程树**专用内存**从 **约 464 MB（15 个进程）降到约 13 MB（1 个进程）**，
  `msedgewebview2.exe` 进程数归零；
- 变更 收纳盒不再各自散落在桌面，而是**合成一条横向长条**，整条**嵌进任务栏**；
  点长条上的第 N 段弹出第 N 个盒子的面板，新建盒子长条就多一个分段；
- 新增 长条**宽度自适应屏幕**，分段多时**横向滚动**；
- 新增 收纳盒支持**自定义 .ico 图标**（右键「设置图标…」），可一键「恢复默认图标」；
- 优化 支持 **Windows 11 任务栏**，任务栏需留出足够空间来放置收纳盒；
- 新增 设置页「外观」可设**弹窗字体与字号**（默认微软雅黑 12 px，可 10~20 调）；
- 优化 **毛玻璃重做**；
- 新增 有更新时面板标题栏显示「有更新」小牌，点击与托盘「检查更新…」统一跳到
  设置页「关于」，版本说明在页内文本框中滚动查看，**不弹任何窗口**；
- 变更 设置页「**长条置顶**」改名为「**总是置顶**」（含义不变，桌面模式下同样生效）；
- 修复 **Windows 11 任务栏模式下按 Win+D** 后长条消失；
- 变更 **日志默认不写**：新增「功能设置 → 打印诊断信息」开关（默认关）；
- 新增 命令行开关 `--version` / `--paths` / `--dump-config` / `--check-update`，不开界面即可排障；
- 保留 v0.9.x 的主要功能：拖入收纳、面板内拖动排序、框选与 Ctrl 多选、OLE 拖出到桌面、
  新建/删除/解散收纳盒、设置图标、置顶、开机自启、静默检查更新、取色器与吸管、字色自动跟随背景。

**升级说明（重要）**

- **不会自动安装**：程序只提示「有新版本」并打开发行版列表页，需**手动下载 `lightbox.exe` 覆盖旧文件**；
  覆盖前请先退出托盘里的 LightBox。
- **数据不丢、但配置不可逆**：`config.json` 和 `boxes\` 目录位置不变，盒子和里面的图标全部保留。
  首次启动会按版本号迁移一次，把 `config.json` 从 v3 升到 v5：
  丢弃 `group` / `group_pos`，各盒 `x/y` 统一成长条位置，`in_bar` 归 false，并写入 `bar` 配置。
  **迁移后不能再退回 0.9.x 使用**。
- **务必先备份**：覆盖前把整个 exe 所在目录（`config.json` + `boxes\`）复制一份。
  程序自己会留 `config.before-v5.json` 和 `config.backup.json`，但前者存的是 v4 阶段、
  后者每次启动都会被覆盖，都不能当作完整的 v3 原始备份。
- **不再保留的 0.9.x 特性**：组合胶囊团、单盒拖拽嵌入/拖出任务栏、盒子右键「检查更新...」、
  独立更新提示窗口、托盘菜单「新建收纳盒」/「关于 LightBox」（分别移到长条右键与设置页）。
- **新增的设置项**：`panel_font` / `panel_font_size`（弹窗字体与基准字号）、
  `diagnostics`（打印诊断信息，默认 `false`），老配置首次启动自动补默认值（微软雅黑 / 12 / 关），
  不需要手工改 `config.json`；配置结构仍是 v5，不触发迁移。
