# LightBox 更新记录

## v0.9.33
<small>2026-11-08</small>

- 修复 **组合胶囊团「嵌入任务栏」/整团切换时偶发卡死**（保留整体切入效果，建窗加超时看门狗，失败整批回滚）；
- 优化 **圆角模式下设置页、更新提示窗口**同步圆角与背景色（更新页补齐主题接入）；
- 优化 设置页「**背景颜色**」改为**弹窗内取色**，文字颜色说明一并移入；
- 新增 有更新时面板标题栏「**有更新**」按钮、盒子右键菜单「**检查更新...**」；
- 优化 非空盒子右键显示「**解散收纳盒**」（图标全部释放回桌面），空盒才显示「删除收纳盒」；
- 调整 面板「更多」菜单「**按名称排序**」置顶、「解散收纳盒」移至末项。

## v0.9.32
<small>2026-11-07</small>

- 修复 面板图标「**拖动一小段又放回**」误开程序，现在只有**真正单击**才打开；
- 修复 **切换显示模式**（笔记本↔外接、双屏↔单屏、更换主屏）后收纳盒**位置错乱**；
- 新增 **启动时自动检测并修复**切屏遗留的重叠、离散、越界位置。

## v0.9.31
<small>2026-11-05</small>

- 修复 **拖动收纳盒、设置页严重卡顿**（上一版「真透明」在部分显卡环境下导致严重卡顿）；
- 回退 桌面收纳盒**真透明**，恢复**子窗口实色底板**（壁纸直接透出改为底板配色，拖动恢复流畅）；
- 回退 盒子名**颜色跟随壁纸明暗**，恢复按底板明暗自动取字色；
- 修复 拖入图标后点击新图标**偶发卡死强退**（打开图标不再阻塞命令线程）；
- 修复 退出时 WebView2 窗口类未注销干净，残留状态拖慢下次启动；
- 新增 程序日志落盘 `lightbox.log`，异常时便于定位问题。

## v0.9.30
<small>2026-10-28</small>

- 调整 **桌面收纳盒真透明**：去掉底板，直接透出壁纸，拖动时也透明；
- 新增 面板图标右键「**打开文件所在位置**」「**属性**」，调系统同名功能；
- 新增 盒子名**颜色跟随壁纸明暗**：深底白字、浅底黑字，和 Windows 桌面图标一致；
- 调整 名字去掉描边、恢复常规字重；
- 调整 「**嵌入任务栏**」排到现有胶囊**队尾**，放不下则队首，不压任务栏按钮和托盘图标；
- 修复 盒子顶部偶发冒出写着「LightBox」的浅色横幅；
- 修复 面板右键菜单底部被裁；
- 修复 拖走盒子后点桌面，面板不自动收起。

## v0.9.29
<small>2026-10-27</small>

- 新增 **胶囊团**：挨在一起的几个盒子可以组合成一个整体，拖动任意一个成员整团跟手；
  右键「整团嵌入任务栏 / 整团移出任务栏」一起换形态，拖动中停住也一样；右键可「解散胶囊团」；
- 新增 面板弹出位置规则：**绝不盖住自己这个收纳盒**，其次优先开在**上方**、再**左侧**，
  旁边的收纳盒能躲就躲；
- 调整 拖入/拖出任务栏的悬停确认时间 **0.5 秒 → 0.3 秒**（延迟感偏大）；
- 调整 面板标题栏去掉 `＋` 新建按钮（改用托盘菜单「新建收纳盒」）；
- 调整 右键「设置LightBox」改为「设置…」；团成员菜单显示「整团嵌入任务栏 / 整团移出任务栏」；
- 修复 Ctrl 多选后拖动或拖出只带出鼠标点的那一个（拖拽文件名列表多写了一个结尾 0）；
- 修复 Ctrl 多选「看着没选中」—— 鼠标悬停的灰底把选中蓝底盖掉了，选中态改为蓝底 + 描边 + 右上角 ✓；
- 修复 桌面盒子互相覆盖时不吸附（直接扔到另一个盒子上就叠着放下），现在会挪到最近空位，左右都在吸附距离内时优先左侧；
- 修复 胶囊团拖动卡死、从任务栏拖出时鼠标被夹在任务栏那一条里；
- 修复 同一次拖出被触发两遍导致同一个盒子多出一个窗口，守护线程现在会自动清理重复窗口；
- 修复 团成员右键「移入/移出任务栏」只动了被点的那一个。

## v0.9.28
<small>2026-10-26</small>

- 调整：更新检查改为直接读取 Gitee 仓库里的 `version.json`，不再依赖独立更新站点；
- 调整：更新窗口的「立即下载」直接打开 Gitee 发行版页，版本说明与安装包在同一处；
- 说明：本版只改更新通道，盒子行为、外观与配置格式均无变化。

## v0.9.27
<small>2026-10-26</small>

- 修复：Windows 11 任务栏模式下收纳盒无法操作；
- 新增：收纳盒可以嵌入任务栏，鼠标拖动或右键菜单「嵌入任务栏」，始终可见；
- 新增：拖到任务栏区域超过一半停住半秒，不用松手就自动嵌入；从任务栏往上顶住半秒自动还原到桌面；
- 新增：设置页「嵌入任务栏时隐藏名称」，打开后任务栏里只显示图标；
- 新增：任务栏里的图标靠近时自动贴合，永不覆盖其他图标，压到别人身上会挪到离自己最近的空位；
- 调整：默认外观改为 #5A606B 实色底板、关闭毛玻璃与圆角，「嵌入任务栏时隐藏名称」默认关闭；
- 修复：拖动中切换任务栏形态时盒子偶发消失（只露任务栏上沿一条），现由守护线程自动修复；
- 修复：点击设置项后任务栏里的图标跳到设置窗口下方；
- 修复：从桌面拖进任务栏时会覆盖已有图标；
